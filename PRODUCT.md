# Product

## Register

product

## Users

Developers, founders, and engineering teams supervising Claude Code, Codex, and other coding agents across the same repositories. They use Agent Nudge while reviewing parallel work, switching sessions, and approaching consequential edits, commits, and decisions.

## Product Purpose

Agent Nudge gives the right agent the smallest verified context delta before it acts. Success means fewer conflicting edits, repeated failures, stale decisions, and expensive re-explanation—without a shared-memory dump or noisy broadcast feed.

## Brand Personality

Direct, vigilant, evidence-led. It should feel like a trusted operations instrument: calm until something matters, decisive when it does, and honest about uncertainty.

## Anti-references

- JobFilter's yellow/black construction-trade identity, lead language, territory mechanics, and scoring labels.
- Generic purple AI SaaS dashboards, glass cards, gradient text, decorative node graphs, and chat-first interfaces.
- Memory products that imply a model “knows” something merely because content was stored or delivered.

## Design Principles

1. Consequence before volume: emphasize the one context change that affects the next action.
2. Show the evidence: every warning exposes source, freshness, recipient reason, and score factors.
3. Quiet by default: the interface earns interruption through relevance and risk.
4. Product before pitch: the landing page shows a real interactive nudge, not abstract promises.
5. Commercial clarity: plain value, transparent packaging, measurable avoided work.

## Accessibility & Inclusion

Target WCAG 2.2 AA. Support full keyboard operation, visible focus, high contrast, non-color state labels, 44px touch targets where applicable, screen-reader naming, and reduced-motion preferences.
